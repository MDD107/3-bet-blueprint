# 3-Bet Blueprint

A free, fully offline poker preflop and 3-bet trainer for Android.

Drill the spots that come up every session: open-raising, facing a raise, and 3-betting — with instant feedback on every decision. No account, no ads, no tracking. Your progress is stored on your device only.

## Features

- Open-raise, vs-raise, and 3-bet drills
- Instant right/wrong feedback with the reasoning
- Score tracking per session
- 100% offline — no network needed, no data collected
