# Poker Examples

Reference scenarios showing the app's teaching style and strategic philosophy.
Use these as the template when writing new quiz scenarios or explanations.

## Format

Each example has:
- **Situation:** stakes, positions, action so far, hero's hand and spot.
- **Preferred answer:** the best default action with sizing.
- **Reason:** why it's the preferred play.
- **Alternative:** when a different line is reasonable.
- **Important:** never claim one universally correct action — always consider
  position, ranges, stack depth, opponent tendencies, and sizing.

## Example 1 (added 2026-10-04)

**Situation:**
$1/$2 NLHE
Hero: BTN
Hand: A♠ Q♠
UTG raises to $6
HJ folds
CO folds
Hero action?

**Preferred answer:**
3-bet to approximately $18-$22.

**Reason:**
AQ suited is strong enough to 3-bet for value against a reasonable
UTG opening range while benefiting from position.

**Alternative:**
Calling can be reasonable depending on opponent tendencies and
effective stacks.

**Important:**
Do not claim there is always one universally correct action.
Consider position, ranges, stack depth, opponent tendencies and sizing.
